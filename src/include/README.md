# Core Headers

This directory contains the C header files shared between the code generated by
the weaver, the measurement runtime, and device libraries.

## Headers

- `gm_aspect.h`: defines the core aspect, metric, sampler, flag, and runtime
  configuration types (`GmKind`, `GmMetric`, `GmSampler`, `GmAspect`, `GmFlag`,
  `GmConfig`), the `GmCalibratePowercapFn` callback signature, `gm_workload_pid`,
  and `gm_main`.
- `energy-counter.h`: provides `energy_counter_delta32`, an inline helper that
  computes 32-bit counter deltas while handling `UINT32_MAX` wrap-around.
- `output_file.h`: provides `energy_share_output_file`, an inline helper that
  preserves user read/write permissions and ownership (`SUDO_UID`/`SUDO_GID`)
  when output files are created under `sudo`.

## Notes

- These headers define internal contracts and utility helpers for C components;
  aspect declarations themselves are written in TOML
