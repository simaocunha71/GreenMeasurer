# Source Tree

This directory holds the C source code, shared headers, device libraries, and
top-level build entry point for GreenMeasurer.

## Directory layout

```
src/
├── Makefile
├── README.md
├── devices/   # C device backends and calibration helpers built into libgm_*.a
├── include/   # Shared C headers defining runtime contracts and low-level helpers
└── weaver/    # C measurement runtime (gm_runtime.c) linked into woven executables
```

- `devices/`: C device backends and calibration helpers built into static
  archives (`libgm_*.a`) via `devices/Makefile` (see [devices/README.md](devices/README.md)).
- `include/`: shared C headers (`gm_aspect.h`, `energy-counter.h`,
  `output_file.h`) defining runtime contracts and low-level helpers (see [include/README.md](include/README.md)).
- `weaver/`: C runtime implementation (`gm_runtime.c`) linked into woven
  executables generated by `scripts/weave.py`.
- `Makefile`: top-level build wrapper delegating library targets (`all`,
  `clean`) to `devices/`.

## Building device libraries

```sh
make -C src
```
