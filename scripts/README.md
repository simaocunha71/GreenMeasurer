### Scripts

- `raplLibrariesSetup.sh`: Installs all prerequisites for the study, such as `git`, `cmake`, `lm-sensors`, etc.
- `measure.sh`: Executes experiments on programs.
- `perf_measure.sh`: Collects performance metrics from each program using `perf`.
- `run_powercap_calibration.sh`: Runs powercap calibration as used in the study.
